# Grok Crew 1.0.8

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: 홈페이지에서 인증한 뒤 열리는 Google 드라이브 파일. 이미 설치한 책상은 [v1.0.8 업데이트](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.8)를 봅니다. 설치 파일은 Grok-crew-test 릴리스에만 올립니다.

1.0.7과 같은 길입니다. 받아서 엽니다.

## 1.0.7에서 달라진 것

- **숨기기와 종료는 다릅니다.** 창을 닫으면 트레이에 숨고 연결은 그대로입니다. **종료**는 자리를 끊고 프로그램을 끕니다. 제목줄 **종료**는 창이 넓어도 가리지 않습니다.
- **어제랑 같게**가 기획·수집·편집 세 자리 연결 글을 한 번에 복사합니다. 자동 대기에는 **다시 복사**가 있습니다. 어제 고른 나라·레시피·언어만 기억합니다. 토큰은 저장하지 않습니다.
- **연결**에도 크루 보드가 있습니다. 남긴 `detail.note`만 보여 줍니다. 다음 자리가 비어 있으면, 그 자리가 받을 일이 있을 때만 "다음 자리 · 연결되지않음"을 붙입니다.
- 7214가 안 열려 있으면 노란 안내가 납니다. 파란 보호 화면은 **추가 정보 → 그래도 실행** 다음에 맞춰 안내합니다.
- 영어·중국어·일본어 자리 이름과 버튼 글을 고쳤습니다. 램프는 여전히 연결됨 / 연결되지않음만 씁니다.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 고른 뒤에만 받고, 그다음 책상을 복사합니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.7이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결** 글은 1.0.7과 같습니다. 나라를 바꿨으면 다시 복사하세요. 어제랑 같게를 쓰면 세 자리를 한 번에 복사합니다.
