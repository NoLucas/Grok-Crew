# Grok Crew 1.0.20

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: [Grok-crew-test v1.0.20](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.20)과 [Grok-Crew v1.0.20](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.20). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.19와 같은 길입니다. 받아서 엽니다.

## 1.0.19에서 달라진 것

- **연결됨** 불은 이 Windows에 들어온 뒤에만 켜집니다. 채팅에서 「연결됨」이라고 하거나 `GROK_CREW_OK`만 클립보드에 있어도 불이 아닙니다.
- 이미 붙은 Grok 자리는 **시작** 이후 `next-invite`를 한 번 읽습니다. 다시 복사는 숨깁니다. 책상은 초대문을 가로채지 않습니다.
- 이 대기를 연 뒤에 새로 온 인박스 파일은 규격 id가 없어도 **여기에 놓기**를 닫을 수 있습니다. 어제 남은 파일은 닫지 않습니다.
- 끝난 컷의 집은 **여기에 놓기**입니다. 최근기록에도 같은 파일입니다. 두 곳에서 찾지 않습니다.
- 이미 붙은 봇은 연결 글을 다시 복사하세요.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.19가 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 봇 창에 붙입니다. 봇이 두 줄로 답하면 이 책상이 입장합니다. 불은 이 Windows 체크인 뒤에만 켜집니다.
