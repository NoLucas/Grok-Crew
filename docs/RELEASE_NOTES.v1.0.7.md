# Grok Crew 1.0.7

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: 홈페이지에서 인증한 뒤 열리는 Google 드라이브 파일. 이미 설치한 책상은 [v1.0.7 업데이트](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.7)를 봅니다.

1.0.6과 같은 길입니다. 받아서 엽니다.

## 1.0.6에서 달라진 것

- **종료**를 누르면 `grok-crew-studio.exe`와 그 자식 프로세스까지 끕니다. 1.0.6은 창과 트레이는 꺼져도 작업 관리자에 사이드카가 남을 수 있었습니다. 창을 닫아 숨기면 연결은 그대로입니다.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 고른 뒤에만 받고, 그다음 책상을 복사합니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.6이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결** 글은 1.0.6과 같습니다. 나라를 바꿨으면 다시 복사하세요.
