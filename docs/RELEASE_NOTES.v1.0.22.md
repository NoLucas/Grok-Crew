# Grok Crew 1.0.22

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: [Grok-crew-test v1.0.22](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.22)과 [Grok-Crew v1.0.22](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.22). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.21과 같은 길입니다. 받아서 엽니다.

## 1.0.21에서 달라진 것

- 어제 이 PC에 남은 OK 입장만으로는 **다시 복사**를 숨기지 않습니다. 이번 실행·이번 연결 글 뒤에 맞춘 입장만 숨깁니다.
- Agent 불도 Grok과 같이 이 Windows 명단 입장 뒤에만 켭니다. 클립보드 OK만으로는 꺼져 있습니다. 시작하기는 이번 실행의 OK로 열 수 있습니다.
- 인박스 개수가 그대로여도 이름·시각·크기가 바뀌면 여기에 놓기로 봅니다. 같은 이름을 덮어쓴 컷도 올라올 수 있습니다.
- 끝난 파일이 수집함·자료함에만 있으면 잘못된 문을 한 줄로 알립니다. 자동으로 수집함을 끝난 컷으로 받지 않습니다.
- 최근기록으로 옮기지 못하면 기존 **다시 옮기기**로 한 번 더 시도합니다.
- 이 책상이 복사한 연결 글 세대가 다르면 시작 칸을 연 채로 둡니다. 이미 붙은 봇은 연결 글을 다시 복사하세요.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.21이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 봇 창에 붙입니다. 불이 켜져 있어도 이 자리 글이 안 갔으면 시작 글을 붙이세요.

## 1.0.22에 없는 것
