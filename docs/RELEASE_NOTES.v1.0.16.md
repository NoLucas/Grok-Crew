# Grok Crew 1.0.16

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: [Grok-crew-test v1.0.16](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.16)과 [Grok-Crew v1.0.16](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.16). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.15와 같은 길입니다. 받아서 엽니다.

## 1.0.15에서 달라진 것

- 자리 확인은 등록된 Windows의 `keep`이 1분마다 합니다. 채팅에 매 분 예약 작업을 만들지 않습니다. 1분을 놓치면 보드에 마지막 확인만 보입니다. 5분이 지나면 자리는 쉬는 중입니다.
- **연결 해제**는 `disconnected`를 보냅니다. `keep`은 그 명령을 보고 멈춥니다. 자리 확인만으로는 끈 램프가 다시 켜지지 않습니다.
- 크루 보드 **대화**는 시작·넘김 `detail.note`가 채팅처럼 쌓입니다. 자리 확인 줄은 대화에 올리지 않습니다. 이미 붙은 봇은 연결 글을 다시 복사하세요.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.15가 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 붙인 뒤 **시작**에 할 말을 적고 **제작 시작**을 누릅니다. 대화는 자리마다 남긴 시작·넘김 한 줄입니다.
