# Grok Crew 1.0.19

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: [Grok-crew-test v1.0.19](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.19)과 [Grok-Crew v1.0.19](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.19). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.18과 같은 길입니다. 받아서 엽니다.

## 1.0.18에서 달라진 것

- **연결** 글 복사만으로는 입장하지 않습니다. 짧은 `GROK_CREW_OK`만 입장입니다.
- `GROK_CREW_OK`만 보내고 멈추면 실패입니다. **시작**에서 나온 글을 그 창에 붙여야 일을 합니다.
- 다른 PC·Linux 자리에는 시작 초대문을 항상 보여 줍니다. 책상 쪽 `still_here`는 초대문 읽기가 아닙니다.
- 왼쪽 파일 카드에서 미리보기를 정지할 수 있습니다.
- 이미 붙은 봇은 연결 글을 다시 복사하세요.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.18이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 봇 창에 붙입니다. 봇이 `GROK_CREW_OK`만 보내고 멈추면 **시작** 글을 그 창에 붙입니다.
