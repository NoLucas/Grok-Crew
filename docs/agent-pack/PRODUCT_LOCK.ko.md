# 상품과 화면 잠금

코드를 열기 전에 이 한 줄과 아닌 것이 맞는지 본다. 어긋나는 기능은 만들지 않는다.

## 한 줄

손님이 쓰는 PC 프로그램이다. 쓰던 **Grok Bot**이나 Agent를 붙이면, 다듬은 파일이 **이 PC 폴더**에 남는다. 계정 없이 연다. 지금 트랙은 무료다.

웹사이트가 아니다. “우리가 영상을 만들어 준다”가 아니다.

## 아닌 것

- 클라우드 편집기, 브라우저에서 자르는 사이트
- 구독, 로그인 벽, 컷당 크레딧
- 인스타·틱톡·유튜브 자동 올리기
- 로그인된 SNS를 긁는 일. 이 책상도 긁지 않는다
- 봇에게 `127.0.0.1`이나 토큰을 보여 주는 일
- 회사 공용 git 편지함을 손님 기본 문으로 열기
- 첫 화면 음성 마법사로 시작을 막기 (설치가 목소리를 이미 두면 TTS 창은 닫힘)
- 퍼센트 바, “봇이 읽었다” 가짜, 램프 세 번째 단어

## 손님 한 바퀴

1. `GrokCrew-Windows.exe`를 연다. 계정 없음. 고르지 않은 TTS는 Kokoro-82M.
2. **연결**에서 붙일 글을 봇 창에 넣는다. 복사만으로는 불이 아니다.
3. **시작**에 하고 싶은 말을 적고 **제작 시작**.
4. 이 Windows에 Grok 자리가 들어와 있으면 그 자리가 `next-invite`를 한 번 읽는다. 아니면 사람이 시작 글을 그 창에 붙인다.
5. 끝난 컷은 **여기에 놓기**. **최근기록**에도 같은 파일.
6. **이 PC에 저장**. 올리기는 한 번 더 고를 때만.

실패하면 **그 칸**이 고치는 말을 한다. 시작을 먼저 열라고 하지 않는다.

## 화면 문구 잠금

바꾸지 않는다. 번역은 같은 뜻만.

| 자리 | 잠금 |
|---|---|
| 문 | planner / collector / editor 만 |
| 시작 칩 | 내파일/주소, 스타일, TTS생성, 업로드 위치 |
| 스타일 칩 이름 | 릴스, 틱톡, 유튜브 쇼츠, 유튜브 본편 (`recipeFallbackLabel`) |
| 도구 | 영상제목 설정 \| 내 영상 재편집 \| 자막 체크 |
| 소리 칸 | tts생성 + 페르소나. **내 목소리 없음** |
| 기본 TTS | Kokoro-82M |
| 램프 | **연결됨** / **연결되지않음** 만. 끊김이라는 단어를 손님 불에 쓰지 않음 |
| 보드 leftover | 마지막 확인 N분 전 (`seconds_since_checkin >= 60`) |
| 초대 붙여넣기 이름 | `Grok Bot 기획자` / `Grok Bot 스크래핑` / `Grok Bot 편집자` |
| 연결·요약 표시 이름 | `Grok Bot 1 -기획자`처럼 번호 |

## 자리와 스킬

연결 글에 이미 붙는다. 손님이 프롬프트를 다시 짜지 않는다.

| 자리 | 기본 | 추가 |
|---|---|---|
| 기획자 | `planner` | `edit-plan` |
| 스크래핑 | `scraper` | `public-pick` (검색 없음. 기획자가 적은 직접 URL만) |
| 편집자 | `editor` | `cut-to-plan` |

원문: `public/bot-skills/`. 이 프로그램은 사이트를 긁지 않는다.

## 기계 (다시 짓지 말 것)

```
손님 Windows
  Electron 창          nodeIntegration:false. 토큰을 렌더러에 안 줌
  Local Studio         127.0.0.1만. 실행마다 포트·토큰
    studio.db          이 PC SQLite
    workspace/         원본·컷·인박스·아웃박스
```

회사 Postgres 없음. 오늘 일 서버 없음. 창 기억은 localStorage. 장부는 SQLite.
