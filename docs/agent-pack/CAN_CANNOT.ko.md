# 고칠 수 있는 것 / 못 고치는 것

아이디어가 세 센서 밖에 있으면 구현하지 말고 이 표를 보여 준다.

## 책상에서 더 고칠 수 있는 것

이 PC가 이미 보는 명단·클립보드·인박스·최근기록만 바꾼다.

| 항목 | 하는 일 |
|---|---|
| 어제 저장된 OK로 다시 복사 숨김 | 이번 실행·이번 연결 글 이후에만 숨김 |
| Agent 불을 Grok과 같게 | 명단 입장 뒤에만 (결정 필요) |
| 같은 pending 덮어쓰기 | 파일 시각·크기를 봄 |
| 다른 문(수집함)에만 둔 파일 | 잘못된 문을 알리거나 그 문도 받음 |
| 최근기록 이동 재시도 | 실패 후 버튼 |
| 연결 글이 옛 버전 | 복사 시각을 기억해 시작 칸을 더 연다 |
| 서명된 exe | **인증서를 받은 뒤.** 코드만으로는 안 됨 |
| 손님 Drive exe | 덮으라고 **명시한 뒤** |

## 절대로 못 고치는 것

| 항목 | 이유 |
|---|---|
| 책상이 Grok 채팅을 읽기 | 다른 프로그램. 센서 없음 |
| 봇 창에 글을 자동으로 붙이기 | 다른 앱 입력칸 |
| Linux·다른 PC가 이 Windows `127.0.0.1`을 열기 | 그 주소는 봇 컴퓨터 루프백 |
| 봇이 next-invite/PowerShell을 치게 강제 | 실행은 봇 |
| 책상이 next-invite를 대신 읽기 | 자리 일을 훔침. 고친 척만 됨 |
| 봇이 만든 채팅 루틴을 원격으로 지우기 | Grok 계정은 밖 |
| 봇 파일 = 연결됨 | 일은 입장이 아님. 불이 거짓이 됨 |
| 이 클라우드에서 운영자 7214를 열기 | 운영자 Windows |
| 인증서 없이 서명된 exe | 도장은 신청하는 물건 |
| 채팅에 토큰을 넣어 원격 접속 | 보안 경계. 구멍 상품 |

## 한 줄 기준

**이 PC가 이미 보는 것**은 고친다. **다른 창이 말하는 것, 다른 컴퓨터의 루프백, 봇이 글을 실행하는지**는 대신할 수 없다.

손님에게는 짧게: 연결 글을 다시 붙이거나, 연결 해제 후 다시 붙이거나, 시작 글을 그 창에 붙인다.
