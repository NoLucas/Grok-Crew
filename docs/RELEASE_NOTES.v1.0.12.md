# Grok Crew 1.0.12

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: 이 태그 [v1.0.12](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.12). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다. 설치 파일은 Grok-crew-test 릴리스에만 올립니다.

1.0.11과 같은 길입니다. 받아서 엽니다.

## 1.0.11에서 달라진 것

- **시작 → TTS생성**의 말투는 이 PC에 받은 모델이 말할 수 있는 언어만 보입니다. 목록은 설치 exe 카탈로그에서 정합니다.
- 지금 기본인 Kokoro-82M에는 **한국어 언어팩이 없습니다.** 한국어 칩은 나오지 않고, 예전에 한국어로 저장한 값은 미국 영어로 맞춥니다.
- 미리듣기는 이 창의 컴퓨터 음성이 아니라 **Kokoro-82M WAV**입니다.
- 영어·중국어·일본어 TTS 문구를 요즘 쓰는 말로 고쳤습니다.
- 편집자가 `handoff-inbox/editor`에 폴더 대신 `mp4`만 두면, 그 컷도 시작 칸에서 엽니다.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.11이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **시작 → TTS생성**을 켜면 말투에 미국 영어·영국 영어·중국어·일본어만 보여야 합니다. 한국어가 보이면 이전 설치가 아직 켜져 있는 것입니다.
