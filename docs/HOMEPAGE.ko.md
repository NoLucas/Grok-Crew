# 홈페이지는 이 저장소에 두지 않는다

손님에게 주는 것은 GitHub Release의 `GrokCrew-Windows.exe`다. 제품은 이 PC에 두는 프로그램이다.

`/` 는 책상이다. 랜딩으로 바꾸지 않는다.

받기 안내 사이트(`public/home.html`, `/home`, `POST /api/get`, `connect-install.js`)는 운영자만 이 컴퓨터에 둔다. GitHub 공개 저장소에 올리지 않는다. 로컬 원본 잠금은 `docs/HOMEPAGE.local.ko.md`다.

## 하지 않는 것

- `/` 을 랜딩으로 바꾸기
- 이메일 없이 오늘 일을 시작하지 못하게 막기
- Pro / Team 가격 페이지, 결제, OAuth
- 우리가 영상을 만들어 준다는 문장
- 사이트 원본을 GitHub에 다시 올리기

파일은 [Grok Crew v1.0.1](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.1)에서 받는다.
