# 홈페이지 트랙은 끊었다

공개 사이트를 이 저장소에서 만들지 않는다. 라이브 chatgpt.site와도 연결하지 않는다.

제품은 이 PC에 두는 프로그램이다. 받는다 → 연다 → 연결한다 → 자동에서 적는다 → 붙인다.

## 하지 않는 것

- 새 랜딩, `/get`, `GROK_CREW_PUBLIC_SITE`
- chatgpt.site에 `connect-install.js`를 꽂기
- 그 사이트가 `POST /api/get`을 부르게 CORS를 열기
- Pro / Team 가격 페이지, 결제, OAuth

파일은 GitHub Release의 `GrokCrew-Windows.exe`로 받는다. 이메일이 없어도 창 안의 오늘 일은 된다.

예전에 검수하던 페이지 사본은 `docs/archive/`에만 있다. 공개 주소로 다시 올리지 않는다.
