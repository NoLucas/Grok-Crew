# 홈페이지는 이 저장소에 두지 않는다

손님에게 주는 것은 Google 드라이브의 `GrokCrew-Windows.exe`다. 제품은 이 PC에 두는 프로그램이다.

`/` 는 책상이다. 랜딩으로 바꾸지 않는다.

받기 안내 사이트(`public/home.html`, `/home`, `POST /api/get`, `connect-install.js`)는 운영자만 이 컴퓨터에 둔다. GitHub 공개 저장소에 올리지 않는다. 로컬 원본 잠금은 `docs/HOMEPAGE.local.ko.md`다.

운영자 홈페이지는 인증된 메일만 문이다. 확인 뒤에는 GitHub Release URL을 주지 않고, Google 드라이브의 `GrokCrew-Windows.exe`로 보낸다. 이 서버는 exe를 호스트하거나 중계하지 않는다.

## 하지 않는 것

- `/` 을 랜딩으로 바꾸기
- 책상 **시작**을 이메일로 막기. 운영자 홈페이지 받기는 인증된 메일만 문이다
- Pro / Team 가격 페이지, 결제, OAuth
- 우리가 영상을 만들어 준다는 문장
- 사이트 원본을 GitHub에 다시 올리기
- 이 앱이 exe를 받아서 다시 흘려 주기

파일은 운영자 Google 드라이브의 `GrokCrew-Windows.exe`에서 받는다. 그 파일은 “링크가 있는 모든 사용자”로 공유한다.
