# Grok Crew 1.0.14

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: 이 태그 [v1.0.14](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.14). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다. 설치 파일은 Grok-crew-test 릴리스에만 올립니다.

1.0.13과 같은 길입니다. 받아서 엽니다.

## 1.0.13에서 달라진 것

- **제작 시작**은 봇이 붙어 있고 할 말만 있으면 됩니다. 칩을 켠 경우에만 그 칸을 검사합니다.
- 시작 칸 안내는 **메세지를 입력하세요**입니다. 아래 설명 문장, 자리 램프 배너, 쓰이지 않던 명령 막대는 없습니다.
- 왼쪽은 위가 폴더, 아래가 그 폴더의 파일입니다. 파일 카드는 미리보기나 짧은 MP4 이름만 보여 줍니다.
- 붙은 봇 이름은 번호가 붙습니다. 사용자 설정과 보내기는 가운데 두고, 화면의 v2 표시는 없습니다.
- 수집 주소는 IPv6로 감싼 사설망과 숫자 IP도 거절합니다. 책상이 붙는 스튜디오 주소는 이 PC 루프백만 따릅니다.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.13이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **시작**에 할 말을 적고 봇이 붙어 있으면 **제작 시작**이 켜져야 합니다.
