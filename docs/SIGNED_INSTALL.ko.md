# 서명된 설치 — 받아서 바로 열리게

손님이 사는 것은 서명이라는 기술이 아니다. **받아서 바로 열 수 있는 설치**다. 파란 보호 화면에서 많이 그만둔다. 이 판이 그 입구만 고친다.

서버 없음. 우리 DB 없음. 계정 없음. P5 없음. Mac 공증 없음. 자동의 한 바퀴는 그대로다.

추론은 `docs/STACK.ko.md`. 구현 잠금은 `docs/BUILD.ko.md`. 이 문서가 **지금 가는 길의 순서**다.

가격·인증서 구매·태그·릴리스는 Maintainer다. CI에 비밀을 연결하는 계약은 Codex다. 서명된 뒤에 도움말을 접는 것은 화면이다.

## 한 줄

`GrokCrew-Windows.exe`를 더블클릭했을 때, Windows가 “알 수 없는 게시자”로 막지 않게 한다. 프로그램·봇·파일 규칙은 바꾸지 않는다.

## 이미 있는 것 / 없는 것

| 이미 있음 | 아직 없음 |
|---|---|
| 이 계정용 원클릭 NSIS. 관리자 비밀번호 없음 | 설치 파일에 게시자 서명이 없음 |
| `npm run desktop:dist`, Windows CI가 exe를 만듦 | 릴리스가 서명을 **꺼 둠** (`CSC_IDENTITY_AUTO_DISCOVERY: false`) |
| 안 열리면 그림 세 장 | 깨끗한 Windows에서 “경고가 줄었는지” 확인 |
| GitHub Release에 파일 하나 | 인증서. 저장소에 넣지 않음 |

이 Linux 기계는 손님용 exe를 만들지 않는다. 빌드는 Windows CI 또는 당신 Windows다.

## 당신이 주는 것 (코드가 아님)

채팅·git·이 저장소에 인증서 파일이나 비밀번호를 주지 마세요.

1. **게시자 이름 하나.** 인증서에 찍히는 이름이다. 한 번 정하면 바꾸지 않는다. 바꾸면 평판이 다시 0이다.
2. **서명 수단 하나.** 아래 셋 중 고른다. “바로 열림”을 사려면 일반 서명은 부족한 경우가 많다.
3. **비밀은 GitHub Secrets에만.** 값이 생긴 뒤에 Codex가 CI를 연다.

| 수단 | 손님이 얻는 것 | 당신이 감당하는 것 | 이 길에 맞나 |
|---|---|---|---|
| **Azure Trusted Signing** | 게시자가 보이고, 경고가 빨리 줄어듦. USB 없음. CI에 맞음 | Azure 계정, 신원 확인, 사용량 | **기본으로 고를 것** |
| **EV 인증서** | 게시자가 보이고, 경고가 빨리 줄어듦 | 비싸고, USB 토큰. CI가 번거로움 | Azure를 못 쓸 때 |
| **일반(OV) 인증서** | 게시자 이름은 생김. 파란 화면은 남는 경우가 많음 | 싸지만 “바로 열림”이 안 될 수 있음 | 기본으로 사지 말 것 |

고르지 않으면 S3를 열지 않는다. 비밀 없이 서명 CI를 켜면 릴리스가 깨지거나, 서명 안 된 파일을 서명된 척 올리게 된다.

## 판 — 한 줄이 끝나야 다음

날짜는 적지 않는다.

### S0 — 잠금 (이 문서)

- 상품 문장: 받아서 연다. 로그인 후 설치가 아니다.
- 안 여는 것: 서버, DB, P5, Mac, 인증서를 git에 넣기, `notarize: true`.

### S1 — 게시자와 수단 (Maintainer)

할 일:

- 게시자 이름을 적는다. 개인이면 본명 또는 상호. 회사면 등기 이름과 맞춘다.
- Azure Trusted Signing 또는 EV를 산다. 신원 확인 서류는 Azure/발급사에만 낸다.
- 일반 인증서만 사고 “이제 파란 화면이 없다”고 쓰지 않는다.

완료: 비밀을 만들 수 있는 계정과, 고정한 게시자 이름이 있다.

### S2 — 비밀을 빌드에만 둔다 (Maintainer)

GitHub 저장소 Settings → Secrets. 로컬 `.env`에 넣지 않는다. `launch:verify`는 이름 있음만 본다. 값을 찍지 않는다.

Azure를 고르면 대략 이런 이름이 생긴다. 값은 여기 적지 않는다.

- Azure 테넌트·앱·비밀
- Trusted Signing 계정 이름, 인증서 프로필, 엔드포인트

EV/PFX를 고르면:

- `WIN_CSC_LINK` — PFX. 경로가 아니라 CI가 읽는 방식(보통 base64). Windows만.
- `WIN_CSC_KEY_PASSWORD`

`WIN_`을 쓰는 이유: Mac 공증과 섞지 않기 위함이다. `package.json`의 `build.mac.notarize`는 **false로 둔다.**

완료: 비밀이 CI에만 있고, git status에 인증서 파일이 없다.

### S3 — 릴리스가 서명된 파일만 최신으로 올린다 (Codex)

비밀이 S2에 생긴 뒤에만 연다. 그 전에 이 판의 코드를 넣으면 지금 unsigned 릴리스가 죽거나, 서명을 끄고도 최신인 척한다.

할 일:

- `.github/workflows/release.yml`에서 서명을 꺼 둔 줄을 없앤다. 비밀이 있을 때만 서명한다.
- electron-builder가 **안의 exe와 설치 파일 둘 다** 같은 게시자로 잠그게 한다.
- 빌드 뒤 Windows에서 서명이 있는지 검사한다. 없으면 그 릴리스를 최신으로 올리지 않는다.
- `package.json`에 게시자 이름을 비밀이 아닌 문자열로 고정한다. 인증서 주체와 같아야 한다.
- 스텝 이름을 정직하게 둔다. “unsigned”와 “signed”를 섞어 쓰지 않는다.
- `GROK_CREW_UPDATES_SIGNED`는 서명된 채널이 실제로 올라온 뒤에만 켠다. 이 판에서 제자리 자동 설치를 기본으로 열지 않는다.

건드리는 곳: `release.yml`, 필요하면 `package.json` `build.win`의 게시자 이름. 스키마·`/api/v2`·사이드카 계약은 열지 않는다. `launch.py`의 서명 게이트는 지금도 `ready: false`다. Windows 서명과 Mac 공증을 한 줄로 묶지 말 것 — 바꾸려면 계약 패킷으로.

완료:

- 최신 Release의 `GrokCrew-Windows.exe`에 게시자가 보인다.
- 비밀이 빠지면 파이프라인이 실패하거나, unsigned를 최신으로 올리지 않는다.

### S4 — 깨끗한 Windows에서 연다 (Maintainer)

개발 PC가 아니다. 한 번도 이 프로그램을 안 깐 Windows.

1. 릴리스에서 파일 하나를 받는다.
2. 더블클릭한다. 관리자 비밀번호가 없어야 한다.
3. 파란 화면이 뜨는지, 게시자 이름이 우리가 정한 이름인지 적는다.
4. 계정 없이 창이 열린다.
5. 연결 → 자동 한 줄 → 저장이 되는지만 본다. 올리지 않는다.

서명이 있어도 첫 다운로드에서는 경고가 남을 수 있다. 그때는 그림 세 장이 아직 맞다. “경고가 없다”는 S4에서 본 뒤에만 쓴다.

완료: 받은 파일이 열리고, 한 바퀴가 깨지지 않았다. 경고가 남으면 그걸 숨기지 않는다.

### S5 — 손님 문장 (화면, S4 이후)

경고가 **실제로** 줄었을 때만.

- README·릴리스는 여전히 파일 하나. `GrokCrew-Windows.exe`.
- “서명된 설치를 사세요”라고 쓰지 않는다. **받아서 연다.**
- 파란 화면이 아직 있으면 그림 세 장을 남긴다. 없어졌으면 **안 열리면**을 접는다.
- 로그인 후 받기가 되면 이 판이 실패한 것이다.

### S6 — 같은 게시자로 쌓기 (운영, 코드 아님)

- 게시자 이름을 바꾸지 않는다.
- 인증서를 다른 상호로 다시 발급하지 않는다.
- 받는 곳이 GitHub Release 하나다. 이름 다른 exe를 여러 사이트에 뿌리지 않는다.

평판은 기능이 아니다. S3를 여러 번 반복한다고 빨라지지 않는다.

## 검수 네 줄

1. 계정 없이 열린다.
2. 설치가 관리자를 기본으로 묻지 않는다.
3. 다른 컴퓨터의 봇이 이 주소를 열게 되지 않는다.
4. 결과물은 손님 폴더다. 우리 테이블이 아니다.

한 줄이라도 아니면 그 커밋은 이 길이 아니다.

## 하지 않음

- 우리 서버·우리 DB를 서명 때문에 열기
- P5, 로그인, 크레딧
- `notarize: true`, Mac 공증 자격 증명을 이 판에 섞기
- 인증서·PFX·비밀번호를 저장소나 채팅에 넣기
- 서명 안 된 파일을 최신으로 두고 “이제 바로 열린다”고 쓰기
- 제자리 자동 업데이트를 이 판의 기본 상품으로 열기
- 모든 계정 exe·압축 zip을 기본 버튼으로 올리기
