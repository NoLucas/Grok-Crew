# 서명된 설치 — 쉬운 설명부터

손님이 사는 것은 “서명”이 아니다. **받아서 바로 열리는 프로그램**이다. 아래는 같은 말을 풀어서 쓴 것이다. 짧은 실행 순서는 맨 아래 **순서**에 있다.

서버를 사지 않는다. 손님 계정을 만들지 않는다. 프로그램이 하는 일(봇에게 오늘 일을 넘기고, 파일을 이 컴퓨터에 두기)은 하나도 바꾸지 않는다. 고치는 것은 **파일을 더블클릭했을 때 Windows가 막는 그 순간**뿐이다.

## 지금 손님에게 일어나는 일

1. 손님이 `GrokCrew-Windows.exe`를 받는다.
2. 더블클릭한다.
3. 파란 화면이 뜬다. “Windows의 PC 보호”. 알 수 없는 게시자라고 한다.
4. **추가 정보 → 그래도 실행**을 눌러야 열린다.
5. 여기서 많은 사람이 바이러스로 생각하고 그만둔다.

프로그램이 나쁜 게 아니다. Windows는 **누가 만든 파일인지 모를 때** 이렇게 막는다. 지금 우리 파일에는 “이 사람은 ○○입니다”라는 도장이 없다. 그래서 “알 수 없는 게시자”다.

계정용 설치는 이미 된다. 관리자 비밀번호도 안 묻는다. 막히는 지점은 설치 마법사가 아니라 **이 파란 화면**이다.

## “서명”이 일상에서 뭐길래

주민등록증에 가깝다. 파일 끝에 “이 파일은 ○○가 만들었고, 받은 뒤 누가 몰래 바꾸지 않았다”는 도장을 찍는 것이다.

- 도장이 있으면 Windows가 게시자 이름을 보여 준다. 예: `홍길동` 또는 `길동 스튜디오`.
- 도장이 있으면 “정체 불명 파일”보다 덜 위험하다고 본다. 파란 화면이 줄어들거나, 바로 열린다.
- 도장이 없어도 프로그램은 돌아간다. 다만 손님이 첫 화면에서 멈춘다.

이 도장은 **우리 집 서버나 손님 데이터베이스가 아니다.** Microsoft(또는 도장을 파는 회사)가 “이 사람이 진짜로 이 이름이다”를 확인해 준 뒤, 우리가 설치 파일을 만들 때마다 찍는 것이다.

코드를 고친다고 도장이 생기지 않는다. 내가 저장소 안에서 만들어 줄 수 있는 물건이 아니다. 당신이 본인(또는 사업자)으로 신청해서 받아야 한다.

## 왜 서버·DB가 아닌가

파란 화면은 Windows와 그 도장 사이의 일이다. 손님이 오늘 올릴 말을 적는 것과 무관하다.

- 서버를 켜도 파란 화면은 안 사라진다.
- 손님 장부를 구름에 올려도 파란 화면은 안 사라진다.
- 도장을 받아 파일에 찍으면, 예전처럼 이 컴퓨터에서 계정 없이 열린다.

그래서 이 길에서는 서버와 DB를 준비하지 않는다.

## 당신이 정해야 하는 것 두 가지

채팅에 도장 파일이나 비밀번호를 보내지 마세요. 저장소에도 넣지 마세요.

### 1. 손님에게 보여 줄 이름

Windows가 “게시자”로 보여 주는 한 줄이다.

- **사업자가 없으면 본명이다.** 상호를 지어 넣지 않는다. Windows가 확인하는 것은 등기된 회사가 아니라, 신분증의 이름이다.
- **한 번 정하면 바꾸지 않는다.** 나중에 사업자를 내고 회사 이름으로 바꾸면, Windows가 다른 사람으로 보고 파란 화면이 다시 길어진다.

사업자를 도장 때문에 지금 만들 필요는 없다.

### 2. 도장을 어디서 받을지 — 사업자가 없을 때

예전에 기본으로 적어 둔 두 가지는, **한국에 있고 사업자가 없으면 지금 거의 못 받는다.**

| 도장 | 사업자 없이 | 한국에서 | 비고 |
|---|---|---|---|
| 마이크로소프트 도장 (Azure / Artifact Signing) | 개인 경로는 미국·캐나다 쪽에 가깝다 | 공개 신원 확인이 한국을 안 받는다는 안내가 있다 | 지금은 고르지 말 것 |
| 비싼 USB 도장 (EV) | 회사만 받는다 | 사업자 서류가 필요하다 | 지금은 고르지 말 것 |
| **개인 표준 도장** | **신분증 + 본인 앞으로 된 공과금 고지서로 받는다** | 한국 개인도 신청하는 회사가 있다 (예: Certum Standard) | **지금 고를 수 있는 도장** |
| 오픈소스 전용 도장 | 개인만 준다 | 상업으로 팔면 회수한다 | 이 프로그램은 파는 물건이다. 쓰지 말 것 |

개인 표준 도장을 찍으면 Windows에 **당신 본명**이 게시자로 보인다. “알 수 없음”보다는 낫다. 다만 EV·마이크로소프트 도장처럼 파란 화면이 바로 사라지지는 않는 경우가 많다. 같은 이름으로 받는 사람이 쌓이면 줄어든다. **사고 “이제 경고가 없다”고 쓰면 안 된다.**

도장을 당장 안 사도 된다. 그때는 지금처럼 그림 세 장(추가 정보 → 그래도 실행)이 설치의 일부다. 프로그램은 그대로 돌아간다.

### 3. 그 외에 사람들이 묻는 길

사업자 없이 “도장만 빼고 파란 화면을 없애는” 마법은 없다. Windows가 모르는 파일을 막는 것이기 때문이다. 남는 선택은 아래뿐이다.

| 길 | 되는가 | 이 상품에 맞나 |
|---|---|---|
| 그림 세 장으로 연다 | 된다. 지금 이 길 | **기본.** 서버·사업자·도장 없음 |
| 개인 표준 도장 | 된다. 본명 + 신분증 | 이름표는 생긴다. 파란 화면이 바로 없어지진 않을 수 있음 |
| Microsoft Store에 올린다 | 개인 개발자 계정으로 올릴 수는 있다. 마이크로소프트가 대신 찍어 준다 | **다른 입구다.** 파일 하나가 아니다. 창+사이드카를 스토어 상자에 넣어야 하고, 심사가 있다. 지금 판이 아님 |
| 압축 파일로 준다 | 이미 예비로 있다 | 안의 exe를 열면 파란 화면이 또 뜰 수 있다. 기본 버튼이 아님 |
| 받는 횟수가 쌓인다 | 가끔 경고가 줄어든다 | 사는 물건이 아니다. 기다림이다 |
| 개인이 홈택스에서 사업자를 낸다 | 나중에 EV·마이크로소프트 도장의 문이 열릴 수 있다 | 도장 때문에 지금 낼 필요는 없다 |
| 내가 만든 도장, 친구 회사 도장, 스마트스크린 끄기 | 기술적으로는 된다 | **하지 말 것.** 더 위험해 보이거나, 남의 이름이 된다 |
| 오픈소스 전용 도장 | 개인에게 준다 | 이 프로그램은 파는 물건이다. 쓰면 회수된다 |

스토어는 “받아서 연다”를 “스토어에서 설치한다”로 바꾼다. 계정 없이 창이 열리는 것과, 스토어 로그인은 다른 층이다. 사이드카·이 PC 폴더를 스토어 규칙에 맞추는 일은 큰 계약이다. 이 판에서 열지 않는다.

신분증·고지서는 도장 회사에만 낸다. 나에게는 주지 않는다.

## 그 다음, 도장을 어디에 두나

도장과 비밀번호는 **열쇠**다. 코드 옆에 두면 누구나 당신 이름으로 파일을 만들 수 있다.

둘 곳은 GitHub 저장소의 **Secrets**다. 설정 화면에 있는 잠긴 칸이다. 프로그램 소스에는 안 들어간다. 설치 파일을 만드는 기계만 읽는다.

당신이 할 일: 도장을 받은 뒤, 그 잠긴 칸에 넣었다고만 알려 주면 된다. 값을 채팅에 붙여 넣지 않는다.

내가(또는 다음에 코드를 연결하는 사람) 할 일: 설치 파일을 만들 때 그 칸을 읽어서 도장을 찍게 한다. **잠긴 칸이 생기기 전에는 이 코드를 넣지 않는다.** 넣으면 지금 올라가는 파일이 깨지거나, 도장 없는 파일을 “이제 안전하다”고 올리게 된다.

지금 자동으로 만들어지는 설치 파일은 **도장을 일부러 안 찍게** 되어 있다. 열쇠가 없어서다.

## 도장을 찍은 뒤에 당신이 확인하는 것

개발에 쓰던 컴퓨터가 아니라, **이 프로그램을 한 번도 안 깐 Windows**에서 한다.

1. 사이트에서 파일 하나를 받는다. 이름은 그대로 `GrokCrew-Windows.exe`.
2. 더블클릭한다. 관리자 비밀번호가 나오면 실패한 것이다. 지금은 안 물어야 한다.
3. 파란 화면이 뜨는지 본다. 뜨면 게시자 이름이 우리가 정한 이름인지 본다.
4. 계정 없이 창이 열리는지 본다.
5. 봇을 붙이고, 오늘 올릴 말 한 줄을 적고, 파일이 이 컴퓨터에 남는지 본다. 올리지 않아도 된다.

중요: 도장을 찍어도 **처음에 한두 번은 파란 화면이 남을 수 있다.** Windows가 “이 이름을 처음 본다”고 생각하기 때문이다. 같은 이름으로 받는 사람이 쌓이면 경고가 줄어든다. 그래서 확인하기 전에 “이제 경고가 없다”고 쓰면 안 된다. 프로그램 안의 그림 세 장(추가 정보 → 그래도 실행)은, 경고가 실제로 줄어든 뒤에만 접는다.

## 내가 지금 못 하는 것 / 당신이 하면 되는 것

| 하는 사람 | 하는 일 |
|---|---|
| 당신 | 손님에게 보여 줄 이름 정하기 |
| 당신 | 마이크로소프트 도장(또는 EV) 신청. 신분증은 그쪽에만 |
| 당신 | 받은 열쇠를 GitHub Secrets에만 넣기 |
| 당신 | 넣었다고 알려 주기. 값은 보내지 않기 |
| 코드 연결 | 그다음, 설치 파일을 만들 때 도장을 찍게 하기 |
| 당신 | 깨끗한 Windows에서 받아서 열어 보기 |
| 화면 | 경고가 줄어든 뒤에만 “안 열리면” 접기 |

Mac 이야기는 이 길에 없다. 다른 컴퓨터용이다. 나중에 따로 한다.

## 자주 헷갈리는 말

**exe**  
손님이 받는 그 파일. `GrokCrew-Windows.exe`. 더블클릭하면 이 계정에 설치되고 창이 열린다.

**게시자**  
Windows가 “누가 만들었나”로 보여 주는 이름. 지금은 비어 있어서 “알 수 없음”이다.

**인증서 / 서명**  
그 이름을 증명하는 도장. 프로그램 기능이 아니다.

**GitHub Secrets**  
깃허브에 있는 잠긴 칸. 소스 코드가 아니다. 도장 열쇠를 두는 곳.

**CI / 릴리스**  
태그를 올리면 멀리 있는 Windows 컴퓨터가 설치 파일을 만들어 배포 페이지에 올리는 일. 지금 그 컴퓨터는 도장을 안 찍는다.

**S1, S2**  
순서 번호일 뿐이다. 1은 이름과 도장 받기, 2는 열쇠를 잠긴 칸에 두기.

## 순서 (짧은 표)

날짜는 적지 않는다. 한 줄이 끝나야 다음이다.

| 순서 | 누가 | 무엇을 하면 끝나는가 |
|---|---|---|
| 0 | 이미 함 | 이 길로 가기로 함. 서버·계정·봇 읽기는 열지 않음 |
| 1 | 당신 | 게시자는 본명. 사업자 없으면 개인 표준 도장(또는 당분간 도장 없이 그림 세 장) |
| 2 | 당신 | 열쇠를 GitHub Secrets에만 두고, 넣었다고 말함 |
| 3 | 코드 | 새로 올리는 설치 파일에 그 도장이 찍힘. 도장 없는 파일을 최신이라고 올리지 않음 |
| 4 | 당신 | 깨끗한 Windows에서 받아서 연다. 한 바퀴가 사는지 봄 |
| 5 | 화면 | 경고가 실제로 줄어든 뒤에만 도움말을 접음 |
| 6 | 당신 | 이름을 바꾸지 않고, 받는 곳을 하나로 유지함 |

## 하지 않는 것

- 서명 때문에 서버나 손님 DB를 열기
- 로그인해야만 받게 하기
- 도장 파일·비밀번호를 채팅이나 코드에 넣기
- 싼 도장만 사고 “파란 화면이 없다”고 쓰기
- 확인하기 전에 그림 세 장을 지우기
- 지금 봇이 초대문을 알아서 읽게 하기 (그건 나중 이야기)

## 지금 한 줄

사업자가 없으면 게시자는 본명이다. 지금 살 수 있는 도장은 개인 표준 도장이다. 마이크로소프트·EV는 나중(사업자·지역이 될 때)이다. 도장을 아직 안 사면, 손님이 받는 파일은 지금과 같고 파란 화면이 뜨면 **추가 정보 → 그래도 실행**이 맞다. 개인 도장을 받아 Secrets에 넣었다고 말해 주면, 그다음 설치 파일에 그 도장을 찍는 코드를 연결한다.
