# Grok Crew 1.0.17

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: [Grok-crew-test v1.0.17](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.17)과 [Grok-Crew v1.0.17](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.17). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.16과 같은 길입니다. 받아서 엽니다.

## 1.0.16에서 달라진 것

- 봇은 `GROK_CREW_OK` 한 줄만 보내고 멈춥니다. 채팅에 루틴·예약 작업·`keep`을 만들지 않습니다.
- 그 줄을 **연결** 칸에 붙이면 이 Windows 책상이 입장하고 자리 확인을 합니다.
- Linux Grok은 창이 없다·7214가 없다고 하지 않습니다. 그 말은 등록된 Windows에서만 씁니다.
- 이미 붙은 봇은 연결 글을 다시 복사하세요.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.16이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 봇 창에 붙입니다. 봇이 보낸 `GROK_CREW_OK` 줄을 연결 칸에 붙인 뒤 **시작**에 할 말을 적고 **제작 시작**을 누릅니다.
