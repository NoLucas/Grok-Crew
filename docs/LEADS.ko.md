# 받아 간 사람 — 연락처만, 문은 아님

지금은 무료다. 그래도 나중에 유료가 열리면 소식을 전할 곳이 필요하다. GitHub에서 exe를 받기만 하면 **이름과 이메일은 오지 않는다.** 받는 횟수만 보인다.

서버·DB를 손님 장부로 열지 않는다. 오늘 일을 시작하려면 이메일이 필요하게 만들지 않는다.

무료 잠금은 `docs/FREE.ko.md`.

## 받는 것 / 안 받는 것

| 받아도 되는 것 | 받으면 다른 회사가 되는 것 |
|---|---|
| 이메일 하나 | 로그인해야만 오늘 한 줄을 적기 |
| (선택) 쓰는 봇 이름 | 영상, 폴더 경로, 토큰 |
| “소식 받겠다”는 표시 | 몰래 쓰는 기록, 크레딧 |

손님 컴퓨터의 장부(`studio.db`)에 이 이메일을 넣지 않는다. 우리 Postgres도 지금 열지 않는다. 쌓는 곳은 **당신이 연 폼**이다. 구글 폼, Tally, Formspree처럼 이메일을 모아 주는 칸이면 된다.

## 언제 묻나

연결·시작·저장을 막지 않는다. 자동 아래 **나중에 소식** 칸이다. 건너뛰면 오늘 일은 그대로다.

공개 홈페이지에서 파일을 받을 때는 이메일을 남긴다. 그 문은 이미 있는 사이트다. `docs/HOMEPAGE.ko.md`. 창 안의 오늘 일은 여전히 이메일 없이 된다.

## 당신이 열어야 하는 것

공개 받기 문:

1. 이 앱의 `POST /api/get`이 이메일을 받는다.
2. 홈페이지는 https://grok-crew-local.jinegcc.chatgpt.site 를 그대로 두고 `#install`만 연결한다.
3. AWS 버킷이 없으면 `data/leads.jsonl`에만 쌓인다.

창 안 **나중에 소식** 칸:

1. 주소를 빌드에 `NEXT_PUBLIC_GROK_CREW_NEWS_URL`로 넣거나, 여기 알려 주면 칸에 꽂는다.
2. 주소가 없으면 칸은 “아직 받을 곳이 없습니다. 건너뛰세요”만 한다. 프로그램은 돌아간다. **그 칸의 이메일은 쌓이지 않는다.**

채팅에 받은 손님 이메일을 붙여 넣지 않는다.

## 검수

1. 이메일 없이 **시작**이 된다.
2. 건너뛰면 칸이 접힌다. 일이 멈추지 않는다.
3. 보낸 뒤에는 다시 묻지 않는다.
4. 화면에 구독·크레딧이 없다.
