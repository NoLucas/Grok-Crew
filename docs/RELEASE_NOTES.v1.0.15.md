# Grok Crew 1.0.15

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: 이 태그 [v1.0.15](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.15). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.14와 같은 길입니다. 받아서 엽니다.

## 1.0.14에서 달라진 것

- 같은 Windows에 체크인한 Grok 자리는 **제작 시작** 뒤 대기 초대문을 스스로 읽습니다. 그 자리에는 **다시 복사**가 없습니다. 예전 연결 글이면 연결 탭에서 한 번 다시 붙이세요.
- 왼쪽 폴더의 영상은 미리보기에서 재생할 수 있습니다. 파일 이름을 누르면 그 작업이 열립니다.
- 연결 글·스킬·TTS 유지 문장은 책상 언어(한국어·영어·중국어·일본어)를 따릅니다. 홈페이지와 README도 **시작** / **제작 시작**을 씁니다.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.14가 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 붙인 뒤 **시작**에 할 말을 적고 **제작 시작**을 누릅니다.

## 1.0.15에 없는 것

- 서명된 exe, SNS OAuth, 드라이브 손님용 파일 자동 덮어쓰기
