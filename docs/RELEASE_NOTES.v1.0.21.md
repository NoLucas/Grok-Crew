# Grok Crew 1.0.21

with Grok Bot. 이 PC에서 여는 프로그램입니다.

공개 파일: **Windows에서 열기** → `GrokCrew-Windows.exe`. 받는 곳: [Grok-crew-test v1.0.21](https://github.com/NoLucas/Grok-crew-test/releases/tag/v1.0.21)과 [Grok-Crew v1.0.21](https://github.com/NoLucas/Grok-Crew/releases/tag/v1.0.21). 손님용 Google 드라이브 파일은 덮지 않았습니다. 이미 설치한 책상은 이 업데이트를 봅니다.

1.0.20과 같은 길입니다. 받아서 엽니다.

## 1.0.20에서 달라진 것

- 어제 leftover 명단(`still_here`)만으로는 **다시 복사**를 숨기지 않습니다. 이 Windows에 들어온 자리만 시작 글을 숨깁니다.
- 이 대기를 연 뒤의 인박스 파일만 여기에 놓기를 닫습니다. 대기 시작보다 오래된 폴더는 고르지 않습니다.
- 최근기록으로 옮기지 못하면 그 사실을 한 줄로 알립니다. 컷은 이미 열려 있습니다.
- 이미 붙은 봇은 연결 글을 다시 복사하세요.

## 받아서 연다

1. `GrokCrew-Windows.exe`를 받아 엽니다. 파란 보호 화면이면 **추가 정보 → 그래도 실행**.
2. 설치가 TTS를 묻습니다. 이미 있으면 건너뜁니다. 고르지 않으면 Kokoro-82M입니다.
3. 이미 1.0.20이 있으면 책상을 트레이까지 끈 뒤, 작업 관리자에 `grok-crew-studio.exe`가 있으면 끝내고, 이 파일을 설치하세요.
4. **연결**에서 최신 글을 봇 창에 붙입니다. 불이 켜져 있어도 이 자리 글이 안 갔으면 시작 글을 붙이세요.

## 1.0.21에 없는 것

- 서명된 exe, SNS OAuth, 드라이브 손님용 파일 자동 덮어쓰기
- 봇 창에 연결 글을 자동으로 다시 붙이기, Linux Grok이 이 Windows `next-invite`를 치는 것
