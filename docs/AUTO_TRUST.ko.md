# 자동 신뢰 — P1부터 사업까지

사람은 말과 확인만 하고, 창은 순서와 대기를 맡는다. 이 문서가 **구현 순서**다. 스크랩 원장은 `docs/USER_ORIENTED_IDEAS.ko.md`. 자동이 의미하는 것은 `docs/AUTO_TAB.ko.md`.

새 `/api/v2`는 여기서 만들지 않는다. 3판(같은 PC 봇이 초대문을 읽기)은 P5다. 로그인·구멍·묻지 않고 올리기는 상품화에도 넣지 않는다.

## 방향 한 줄

Grok Crew는 구름 편집기가 아니다. **이 PC의 숏폼 책상**이다. 봇은 옆 창의 손이고, 파일은 항상 여기 남는다. 상품은 “AI가 알아서 올린다”가 아니라 **오늘 한 줄을 맡기고, 기다림이 정직하고, 컷이 이 폴더에 있다**.

## 판

| 판 | 이름 | 필요한 이유 | 기술 | 상태 |
|---|---|---|---|---|
| P1 | 대기 신뢰 | 빈칸·노란등만 있으면 고장으로 보인다 | Auto UI + localStorage + 이미 있는 `wait`/`lastCheckedAt` | 이 커밋 |
| P2 | 매일 반복 | 같은 말을 떠올리고, 시작 전 오해를 끊는다 | 같은 층. 레시피·제목 기억 | 이 커밋 |
| P3 | 자리 비움 | 탭을 나가면 등이 안 보인다. 실패에서 같은 일을 다시 | 타이틀바 점, 다시 시작, 덮을지 묻기 | 이 커밋 |
| P4 | 창이 뒤일 때 | 자리를 완전히 비우면 점이 안 보인다 | 렌더러 `Notification`. Electron main 안 건드림 | 이 커밋 |
| P5 | 읽음 | 대기의 가장 큰 불안 | **계약 후.** 지금은 “모름”이 정직 | 대기 |

P1–P4는 화면과 이 PC 기억만으로 된다. P5만 Codex 계약이다.

## P1 — 대기 신뢰

1. 빈칸이 다음 손을 가리킨다. 봇 없음 → 연결 열기. 대기 중 미리보기 → “오면 여기, 지금은 비어 있음”. 저장 후 → 폴더·다음.
2. **시작**을 누르면 즉시 “보내는 중”. 경고 문장 없음.
3. 노란등 옆 경과 시간. “이 창은 봇이 읽었는지 모름.”
4. 저장 카드는 사람이 닫지 않아도 남는다. 올리지 않았다고 쓴다.
5. **내 파일로 시작**은 봇 대기 문장·끝난 파일 놓기를 쓰지 않는다.

## P2 — 매일 반복

1. 시작 위 **이번 일** 한 장. 봇·스타일·하지 않음(안 올림, 화질 잠금, 이 PC에만).
2. 최근 제목 세 줄 칩.
3. 돌아왔을 때 브리핑. 아까 말 / 지금 / 안 누르면.
4. 연결됨은 “이름 · n분 전”. 주소는 안 보여 준다.

## P3 — 자리 비움

1. **자동** 탭에 점 하나. 노랑=대기, 초록=컷, 빨강=실패. 등 다섯을 헤더에 복제하지 않는다.
2. 실패 한 줄 + **같은 말로 다시**. 화질·문·주소를 건드리지 않는다.
3. 이미 컷이 있는데 다른 파일을 놓으면 덮을지 묻는다.
4. **다른 제목**은 칸만 비운다. 저장한 파일은 그대로다.

## P4 — 창이 뒤일 때

컷이 왔고 `document.hidden`일 때만 OS 알림. 보고 있으면 자동 탭 한 줄이면 충분. `desktop/main.mjs`는 열지 않는다.

## P5 — 하지 않음 (계약)

- 봇이 초대문을 읽었다.
- 같은 PC 봇이 알아서 읽기.
- “이렇게 고쳐”를 봇 brief에 새로 넣기.
- 로그인, QR로 `127.0.0.1`, 묻지 않고 업로드.

계약 요청은 `app/desktop-auto-state.ts` 맨 아래에 이미 있다.

## 검수 두 질문

- **워크벤치:** 서랍을 안 열고 제목 → 시작이 되는가.
- **브리핑:** 30초 안에 상태·어디에 두었나·다음이 읽히는가.

## 상품화

팔리는 것은 모델이 아니다. **오늘 한 컷이 이 PC에 남는 습관**이다.

| 지금 파는 것 | 팔지 않는 것 |
|---|---|
| Windows 책상 + Local Studio. 한 줄 → 봇 → 파일 | 구독 로그인, 구름 타임라인, 자동 업로드 SaaS |
| 연결 한 곳. 다른 PC는 글만. 구멍 없음 | “봇이 내 PC를 연다”는 마법 |
| 규격 잠금. 수집 문 / 편집 문 | 화질을 봇이 바꾸게 하는 프로  knobs |

가격·패키지는 Maintainer가 정한다. 기술적으로 열리는 층만 적는다.

1. **지금:** `GrokCrew-Windows.exe`. 한 사람, 한 PC, 붙인 봇 하나. 값은 설치 마찰(SmartScreen)과 첫 컷까지의 시간이다.
2. **그다음(서버가 올 때):** 계정은 동기화·라이선스용이다. 편집 본문은 여전히 로컬. 로그인을 자동의 문으로 쓰지 않는다.
3. **팀:** 같은 책상을 여러 사람이 쓰지 않는다. 봇 핸드오프가 팀이다. 공유 구름 프로젝트는 로컬 우선과 싸운다. 파일이 남고, 초대문만 옮긴다.
4. **수익 후보 (열지 않음, 후보만):** 좌석 라이선스, 봇 팩(초대문 템플릿), 서명된 설치로 SmartScreen을 줄임. 업로드 API를 기본 상품으로 올리지 않는다 — 그건 내보내기의 선택이다.

확장의 축은 기능 수가 아니다.

- **더 많은 봇 종류** — 연결 목록에 이름만 는다. 자동 화면은 그대로다.
- **더 빠른 같은 PC** — P5 계약. 창 두 개가 하나로 줄어든다. 그때 상품 문장이 바뀐다.
- **더 정직한 대기** — 경과·모름·점·알림. 이미 P1–P4.
- **더 많은 플랫폼에 올리기** — 상품의 중심이 아니다. 저장 다음의 선택이다.

하지 말 확장: 웹 SaaS 편집기, 모바일에서 루프백, 크레딧 미터, 적응형 메뉴, 샘플 자동 재생.

서버·DB를 언제 여는지의 심층 추론은 `docs/STACK.ko.md`. 구현 목록은 `docs/BUILD.ko.md`. 지금 길은 무료로 풀기(`docs/FREE.ko.md`). 도장은 돈 받을 때(`docs/SIGNED_INSTALL.ko.md`). 오늘 일과 컷 저장에는 우리 서버가 없고, 장부는 이 PC의 SQLite다.

## 기술 지도

| 필요 | 쓰는 것 | 안 여는 것 |
|---|---|---|
| 상태·경과·최근 제목 | `localStorage`, `DeskWaitState`, roster `seconds_since_checkin` | 새 스키마, 새 `/api/v2` |
| 다섯 등·헤더 점 | `autoPhaseLamps` / `autoHeaderDot` | 퍼센트 바 |
| 저장 | 이미 있는 로컬 렌더 | 게시 기본값 |
| 뒤 창 알림 | `window.Notification` | Electron main/preload, 트레이 메뉴 개조 |
| 읽음 (P5) | 계약 요청만 | UI에 가짜 읽음 |

Local Studio·Electron·규격 잠금·문 분리는 그대로다.
