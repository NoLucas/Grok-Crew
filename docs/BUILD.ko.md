# 이 아이디어로 간다 — 구현에 필요한 것

잠근 상품: 손님이 이 컴퓨터에 프로그램을 두고, 이미 쓰는 봇에게 오늘 일을 넘기고, 완성 파일을 자기 폴더에 받는다. 웹사이트가 아니다. 계정 없이 연다. 올리는 것은 기본이 아니다.

서버·DB 추론은 `docs/STACK.ko.md`. 자동 화면 순서는 `docs/AUTO_TRUST.ko.md`. 이 문서는 **구현 목록**이다. 새 `/api/v2`는 여기 적혀 있다고 만들지 않는다. P5만 계약 후다.

가격·패키지·태그·서명은 Maintainer다.

## 손님 길 (구현이 맞춰야 하는 것)

1. 프로그램을 연다. 계정 없음.
2. 연결에서 봇을 붙인다. 다른 PC 봇은 이 주소를 열지 못한다. 글과 끝난 파일만 오간다.
3. 자동에 오늘 올릴 말만 적고 시작한다.
4. 프로그램이 일을 복사해 두고, 사람은 봇 창에 붙인다.
5. 컷이 오면 이 화면에서 보고, 이 컴퓨터에 파일로 저장한다.
6. 올리는 것은 저장한 뒤에, 원할 때만.

이 여섯이 한 바퀴다. 한 바퀴 밖은 다음 화면이거나 다른 회사다.

## 이미 있다 — 다시 짓지 말 것

한 바퀴는 이미 이 저장소에 있다. 없는 제품을 처음부터 짜는 일이 아니다.

| 손님 길 | 이미 쓰는 것 | 손대지 말 것 |
|---|---|---|
| 연다 | Electron 창, 이 계정용 NSIS, 사이드카를 exe에 넣음 | 웹 로그인, 설치 마법사, 관리자 기본 |
| 붙인다 | 연결 탭, 페어 코드, `GROK_CREW_OK`, 같은 PC 체크인 | QR로 `127.0.0.1`, 터널, 자동에 연결 UI 복제 |
| 적고 시작한다 | 자동 탭 한 칸, `POST /api/v2/edit-specs`, `source_mode: bot` | 크레딧, 레시피 네 장을 첫 화면에 펼치기 |
| 일을 복사한다 | `GET /api/v2/edit-specs/{id}/invite`, 클립보드 | 초대문을 우리 서버에 올리기 |
| 사람이 붙인다 | 화면에 “그 창에 붙이세요”. 같은 PC가 알아서 읽기는 아직 없음 | UI에 가짜 읽음 |
| 컷이 온다 | 인박스 감시, `POST /api/v2/handoff/pull`, 끝난 파일 놓기 | 받기 버튼, 루프백을 밖으로 열기 |
| 저장한다 | 자동 미리보기, 이 PC 저장 카드, `workspace/` | 저장과 동시에 업로드 |
| 안 올린다 | 게시 기본값 “저장 후 한 번 더” | 예약 발행 팜 |
| 화질 | 로컬 렌더 계약, 레시피 잠금 | 봇이 quality를 바꾸게 두기 |
| 기다림 | P1–P4. 경과, “읽었는지 모름”, 헤더 점, 숨은 창 알림 | 퍼센트 바, “거의 다 됐다” |

기계도 이미 있다.

```
Electron 창
  └── 이 PC만 듣는 Local Studio (127.0.0.1, 실행마다 포트·토큰)
        ├── studio.db     이 PC 장부
        └── workspace/    원본·컷·인박스·아웃박스
```

창 기억은 `localStorage`(페어 코드, 최근 제목, 대기). 장부는 SQLite. 둘 다 이 컴퓨터다. 우리 Postgres 없음. 우리 앱 서버 없음.

## 구현에 필요한 것 — 네 칸

### A. 코드로 이미 닫힌 것 (유지)

손대지 않고 지키는 경계.

- `desktop/main.mjs` — 루프백만, 토큰은 렌더러에 안 줌, `nodeIntegration: false`
- `local_studio/` — SQLite, 핸드오프 두 문, 초대문, pull, 렌더, 게시(선택)
- `app/desktop-bot-*.ts(x)` — 연결만 붙이고 끊음
- `app/desktop-auto-*.ts(x)` — 오늘 일, 대기, 저장
- 검증: `npm run verify:core`, `python -m pytest -q local_studio/tests`

새 기능이 이 경계를 넘으면 그 기능이 틀린 것이다.

### B. 이 아이디어를 끝까지 가려면 아직 남은 것

날짜 없음. 한 줄이 끝나야 다음 줄.

| 순서 | 하는 일 | 누가 | 필요한 기술 | 열지 않는 것 |
|---|---|---|---|---|
| 1 | **손님 한 바퀴를 깨지 않기.** 연결 → 자동 → 붙이기 → 컷 → 저장. 회귀만 | 화면=Claude, 계약=Codex | 이미 있는 테스트·화면 | 새 탭, 새 서버 |
| 2 | **지금은 무료로 푼다.** 지금 가는 길. `docs/FREE.ko.md` | Maintainer가 릴리스에 exe를 올림 | GitHub Release 하나. 계정·결제 없음. 파란 화면은 그림 세 장. 연락처는 선택 칸(`docs/LEADS.ko.md`) | 유료 문, 로그인 문, 크레딧, 이메일 없이 시작 막기, 지금 도장 사기 |
| 3 | **P5 — 같은 PC 봇이 초대문을 읽음.** 무료로 연 다음 | Codex가 계약 먼저. 그다음 화면 | 로컬만. 체크인된 editor 봇, `waiting_for_bot`, 토큰. 요청은 `app/desktop-auto-state.ts` 맨 아래 | 다른 PC가 이 주소를 열게 하기. UI 가짜 읽음 |
| 4 | **받아서 바로 열리게.** 돈 받을 때. `docs/SIGNED_INSTALL.ko.md` | Maintainer가 인증서·비밀. 비밀 뒤 Codex가 CI | 사업자 없으면 게시자는 본명, 도장은 개인 표준 | 인증서를 git에 넣기. 무료인데 유료인 척 |
| 5 | **한 사람 한 PC 권리.** 팔기 시작할 때 | Maintainer + 나중에 작은 확인 | 결제사가 주는 구매 번호. 꺼져 있어도 **시작**은 됨 | 컷당 크레딧, 우리 영장부 |
| 6 | **계정.** 서버가 생긴 뒤만 | 계약 작업으로만 | 구매 확인·설정 묶음 | 자동의 문, 영상 보관, 구름 타임라인 |

1이 기본이다. 2가 지금 길이다. 3은 같은 일을 더 편하게. 4부터는 돈. 돈을 받기 전에 도장·결제·계정을 열지 않는다.

### C. 구현할 때 쓰는 도구 (회사 인프라 아님)

개발·검증에 필요한 것. 손님 서버가 아니다.

| 필요 | 용도 | 없어도 되는 것 |
|---|---|---|
| Node, Python, 로컬 ffmpeg/MoviePy | 창·사이드카·렌더 | 구름 GPU |
| Windows (또는 CI Windows) | 손님에게 줄 exe | 이 Linux 기계에서 최종 exe |
| GitHub Release | exe 올려 두기 | 우리 다운로드 서버 |
| (돈 받을 때) 코드 서명 인증서 | 파란 화면을 줄임 | 우리 서명 서버 |
| (돈 받을 때) 결제사 | 샀다는 번호 | 우리 결제 DB |
| (훨씬 뒤) 작은 확인 API + 작은 DB | 번호↔컴퓨터, 설정 묶음 | Postgres에 영상·타임라인 |

SQLite를 “임시”로 보지 않는다. 이 상품의 장부다. Redis, 동기화 엔진, 객체 저장소를 손님 길에 넣지 않는다.

### D. 구현하지 않는다

백로그에 넣지 않는다.

- 우리가 모델을 빌려 영상을 만듦
- 적으면 알아서 인스타·틱톡에 올림
- 브라우저에 맡기면 우리가 보관·편집
- 봇이 이 컴퓨터를 직접 염 (`127.0.0.1`을 밖으로)
- 영상 하나당 크레딧
- 로그인해야만 오늘 일을 시작
- 여러 명이 구름에서 같은 영상을 같이 편집

## 누가 어느 파일을 만지나

한 줄에 한 책임자. 계약과 화면을 같은 PR에 섞지 않는다.

| 일 | 파일 | 하지 않음 |
|---|---|---|
| 자동·연결 화면 | `app/desktop-auto-*`, `app/desktop-bot-*`, 해당 테스트 | `/api/v2` 새 필드 지어내기 |
| 초대문·인박스·장부·렌더 | `local_studio/**`, 스키마, `handlers.py` | UI가 로컬 우회 계약을 만듦 |
| 창 권한·트레이·업데이트 피드 | `desktop/main.mjs`, preload, relay | 루프백 공개 |
| 설치 파일 이름·NSIS | `package.json` build | 인증서 값을 저장소에 넣음 |
| P5 | Codex 계약 → 그다음 `desktop-auto-desk` | 계약 전에 “읽는 중” |

UI가 새 데이터를 원하면 임시 필드를 만들지 않고 계약 요청만 남긴다. 형식은 `docs/AI_COLLABORATION.ko.md`.

## 한 바퀴 검수

구현이 맞는지 손님 손으로만 본다. 서버 헬스체크가 검수가 아니다.

1. 계정 없이 창이 열린다.
2. 연결에서 봇을 붙인다. 주소가 화면에 없다.
3. 자동에 한 줄을 적고 시작한다. 클립보드에 일이 들어간다.
4. 기다리는 동안 “거의 다 됐다”가 없고, 경과와 “읽었는지 모름”이 있다. (P5 전에는 이 문장이 맞다.)
5. 컷이 오면 이 탭에서 보인다.
6. 저장하면 이 컴퓨터 폴더에 파일이 있다. 올리지 않았다고 적혀 있다.
7. 창을 꺼도 파일은 남는다.

한 줄이라도 아니면 그 커밋은 이 아이디어가 아니다.
