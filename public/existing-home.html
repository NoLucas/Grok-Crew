01 / Why local

영상은 그대로.
Grok이 찾아온다.

Grok Crew는 클라우드 영상 편집 툴이 아닙니다. 같은 PC의 에이전트가 로컬 API를 통해 편집하고, 로컬 MP4를 만듭니다.

클라우드 에디터REMOTE
  • 01원본을 서비스로 업로드해 웹에서 처리
  • 02로그인과 서비스 연결을 먼저 구성
  • 03에이전트는 브라우저와 로컬 파일 사이를 오감

경계: 원본 파일과 편집 주체가 서로 다른 환경

Grok CrewLOCAL-FIRST
  • 01원본, 편집 API, 렌더가 같은 PC에 존재
  • 02Grok Crew 클라우드 계정·API 키 없이 시작
  • 03Claude Code와 Codex가 로컬 API를 직접 호출

증거: 로컬 MP4 렌더 → 큐 또는 자동 게시

02 / Pipeline

한 PC.
다섯 단계.

촬영본에서 게시 큐까지. Grok이 수행하는 실제 순서입니다. 중간에 멈추고 직접 편집해도 됩니다.

Step 01Input

원본 촬영본

로컬의 촬영 파일에서 시작합니다. 클라우드 URL을 붙여 넣는 흐름이 아닙니다.

구체적 증거 · 원본 파일은 같은 PC에 유지

Step 02Map

대본 컷맵

대본을 기준으로 어떤 장면을 남기고 자를지 컷 구조를 잡습니다.

구체적 증거 · 대본에서 장면 단위 컷 지시로

Step 03Method

봇 편집 방식

Grok이 로컬 API로 편집을 수행합니다. 맡길 범위를 정하고, 필요하면 직접 이어받습니다.

구체적 증거 · 같은-PC 에이전트가 편집 주체

Step 04Render

로컬 MP4 렌더

완성본을 원격 작업 결과가 아닌 로컬 MP4 파일로 렌더합니다.

구체적 증거 · 출력 형식은 로컬 MP4

Step 05Publish

큐 또는 자동 게시

완성본을 큐에 두거나 Instagram, TikTok, YouTube로 자동 게시합니다.

구체적 증거 · 세 플랫폼 게시 흐름까지 연결
