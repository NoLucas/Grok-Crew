# Agents

If you are an AI opening this repository in a new chat, start here:

1. Read [`docs/agent-pack/SKILL.md`](docs/agent-pack/SKILL.md).
2. Do not invent the product. The lock is: a local Windows desk. Attach a bot they already use. The file stays on this PC. Free on this track.
3. The desk sees only clipboard, this-PC roster, and the editor inbox. It cannot read Grok chat.
4. Fill [`docs/agent-pack/PACKET.md`](docs/agent-pack/PACKET.md) before editing.
5. Default push remote is `github` → `https://github.com/NoLucas/Grok-crew-test.git`. Do not commit to `main`. Do not commit `.env`, installers, or `verification_screenshots/`.

Roles, contracts, and handoff format: [`docs/AI_COLLABORATION.ko.md`](docs/AI_COLLABORATION.ko.md).

Claude-specific bounds: [`CLAUDE.md`](CLAUDE.md).
