# Grok Crew

<p align="center"><a href="README.md">English</a> &nbsp;·&nbsp; <strong>한국어</strong> &nbsp;·&nbsp; <a href="README.zh.md">简体中文</a> &nbsp;·&nbsp; <a href="README.ja.md">日本語</a></p>

**[Windows에서 열기](https://github.com/NoLucas/Grok-crew-test/releases/latest)** — [`GrokCrew-Windows.exe`](https://github.com/NoLucas/Grok-crew-test/releases/latest)를 받아 더블클릭하세요.

다섯 번입니다. 받는다 → 연다 → 연결한다 → 자동에서 적는다 → 붙인다.

1. **받는다** — 파일 하나, `GrokCrew-Windows.exe`.
2. **연다** — 더블클릭. 파란 보호 화면이면 추가 정보 → 그래도 실행.
3. **연결한다** — 위 **연결** 메뉴에서 합니다. 맨 위가 다른 PC(Grok·Cursor·Claude·내가 만든 에이전트)입니다. 연결 글을 붙인 뒤, 봇이 보낸 `GROK_CREW_OK` 한 줄을 다시 붙입니다. 초록불과 **연결됨**이면 붙은 겁니다.
4. **적는다** — **자동** 탭에 오늘 올릴 말.
5. **붙인다** — 시작이 일을 복사합니다. 그 봇 창에 붙입니다. 컷이 오면 이 탭에 미리보기가 남고, 저장을 묻습니다.

내 영상을 바로 자를 거면 자동의 **내 파일로 시작**에 놓습니다. 로그인은 없습니다.

영상을 맡아 주는 웹사이트가 아닙니다. 봇은 이 PC를 열지 않고, 패키지만 보냅니다.

```
exe를 받는다  →  연다  →  연결한다  →  자동에 말을 적는다  →  일을 붙인다  →  미리보고 이 PC에 저장
```

## 누가 쓰나요

- 릴이 어떻게 나와야 하는지만 정하고 싶은 사람
- 연결된 봇에게 원본과 첫 컷을 맡기되 문을 섞지 않고 싶은 사람
- 완성 파일은 그래도 이 PC에 두고 싶은 사람

시작하려면 계정이 필요 없습니다.

## 화면에 보이는 것

첫 화면은 **연결** 메뉴입니다. 다른 PC가 맨 위이고, 이 PC·Local Studio·GitHub·Runner도 거기서 합니다. 초록불이 **연결됨**입니다. 봇이 붙거나 **내 파일로 시작**으로 영상을 열면 **자동**이 착지하고, 설정·편집·내보내기가 켜집니다. **자동**은 오늘 올릴 말 한 칸과 시작 하나입니다. 맡겨서 만들기와 내 파일로 시작은 자동 안의 두 모드입니다. 연결 UI는 자동에 다시 그리지 않습니다. 샘플은 **샘플로 화면 보기**로만 엽니다. 복사 뒤에는 연결·일 보냄·작업 중·컷 도착·이 PC에, 경과 시간, 아직 없음·도착함·실패가 사람 말로 보입니다. 이 창은 봇이 읽었는지 모릅니다. 저장 카드는 이 PC 폴더를 말하고 올리지 않았다고 씁니다. python·포트·폴더 경로는 펼치기 전에는 없습니다. **더 자세히**와 **고급 도구**는 첫 컷이 온 뒤에만 커집니다. 편집 문으로 온 컷은 받기 버튼 없이 자동 탭에 미리보기가 남습니다. 봇이 저장한 폴더(`inputs/handoff/` 패키지와 자료함 클립)는 한 줄로 접혀 있고, 펼치면 목록 옆에 미리보기가 있습니다. 파일을 오른쪽 클릭하면 미리보기·크게 보기·원본 보기·삭제를 고릅니다. 화질은 규격 잠금이고, 화면 비율·자막과 나머지 편집 조절은 설정에서 바꿀 수 있습니다. 설정에서 유튜브 쇼츠·인스타 릴스·틱톡·사용자 지정을 고른 뒤 지정하고, 지금 값은 따로 이름으로 저장할 수 있습니다. 프로젝트는 폴더로 묶고, 이름 바꾸기와 휴지통(복원·30일 후 삭제)을 쓸 수 있습니다. 밝은 낮·어두운 밤·부드러운 낮·부드러운 밤과 글자 강조·크기는 왼쪽 위 톱니바퀴에서 바꿉니다. 사람은 봇이 쓸 도구를 지정할 수 있고, 실행은 웬만하면 봇이 적힌 API로 합니다. 허브는 카드만 두고 카탈로그 JSON은 접으며, 테마는 이 설정을 따릅니다. 이 앱은 사이트를 긁지 않습니다.

그다음은 다섯 탭입니다.

| 탭 | 하는 일 |
| --- | --- |
| **연결** | 다른 PC, 이 PC, Local Studio, GitHub, Runner |
| **자동** | 오늘 말 → 보내기 → 기다리기 → 미리보기 → 저장 |
| **편집** | 미리보기를 보고 타임라인에서 자릅니다 |
| **설정** | 분위기, 자막, 속도 |
| **내보내기** | 이 컴퓨터에 MP4를 저장하거나, 물어본 뒤에 게시합니다 |

미리보기는 빠르게 보는 초안입니다. 저장하는 파일은 봇이 넘긴 원본으로 만듭니다. 이 컴퓨터에 이미 있는 파일을 직접 여는 것은 규격 아래 선택 사항입니다.

## 영상은 이 컴퓨터에 남습니다

원본, 편집, 완성본은 이 PC에 있습니다. Grok Crew 클라우드 프로젝트도, 시작용 로그인도 없습니다.

게시는 선택입니다. 기본은 **게시 전 확인**입니다. 이미 올라갔을 수 있으면 한 번 더 보내기 전에 다시 묻습니다. Instagram·TikTok·YouTube 계정은 Grok Crew가 만들어 주지 않습니다.

## 선택: 이 PC의 AI에게 시키기

**같은 컴퓨터**에서 이미 AI가 켜져 있다면, 평범한 말로 시킬 수 있습니다. 센 대사만 남기고, 자막 넣고, 세로로 자르고, 파일은 여기에 두고, 올리지는 마.

다른 컴퓨터의 AI는 이 화면을 열 수 없습니다. **연결** 메뉴의 연결 글로 이름만 붙고, 끝난 컷은 이 창에 놓습니다. 영상을 “한번만 보게” 보내지 않습니다.

## 여는 방법

**Windows에서 열기** — [최신 릴리스](https://github.com/NoLucas/Grok-crew-test/releases/latest)에서 `GrokCrew-Windows.exe`를 받아 더블클릭하세요. 이 계정에만 들어갑니다. 관리자 비밀번호를 묻지 않습니다.

Windows가 PC를 보호한다고 하면 **추가 정보 → 그래도 실행**.

이미 누군가 설치해 두었다면 Grok Crew 창을 열면 됩니다. 또는 브라우저에서 [http://localhost:3000](http://localhost:3000/)입니다.

소스로 직접 돌리려면 [Node.js 22 이상](https://nodejs.org/)과 [Python 3.10 이상](https://www.python.org/downloads/)이 필요합니다.

```sh
git clone https://github.com/NoLucas/Grok-Crew.git grok-crew
cd grok-crew
npm run local
```

소스에서 창으로 쓰려면 `npm install` 한 번 후 `npm run desktop`입니다. 첫 실행은 몇 분 걸릴 수 있습니다. 끄려면 `Ctrl+C`.

이 컴퓨터에서 자신의 영상을 만들고 올리는 것은 가능합니다. 소스는 [BUSL-1.1](LICENSE)로 공개되어 있고, 오픈소스 제품은 아닙니다. 질문: [CONTRIBUTING.md](CONTRIBUTING.md).
