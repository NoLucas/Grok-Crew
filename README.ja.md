## だれ向けか

- **Shorts を一人で切るのがつらい人。** タイムラインをゼロから組まなくてよいです。やりたいことを書いてボット窓に貼り、ここで保存します。
- **いま無料です。** ログイン欄はありません。サブスクではありません。カットごとのクレジットもありません。
- **ファイルはこのPCに残ります。** クラウド編集ではありません。

この窓は「こちらが動画を作る」サブスクではありません。すでに使っているボットを付けるプログラムです。

---

## ボットと Agent の内蔵スキル

接続すると、その席のスキルがすでに付きます。企画・収集・編集のプロンプトを自分で書かなくてよいです。

| 席 | 基本スキル | 一緒に付く追加スキル |
|---|---|---|
| **Grok Bot / Agent 企画者** | `planner` — 今日の一言をカット計画に | `edit-plan` — 収集と編集が読む短い計画 |
| **Grok Bot / Agent 収集** | `scraper` — 公開ページだけ選ぶ | `public-pick` — ログイン壁のSNSは書かない |
| **Grok Bot / Agent 編集者** | `editor` — 計画どおりに切る | `cut-to-plan` — シーン順と国の癖を守る |

原文は [`public/bot-skills/`](public/bot-skills/) にあります。付ける文をコピーすると、その席のスキルも一緒に行きます。このプログラムはサイトを掻きません。

## 使い方

1. `GrokCrew-Windows.exe` を開きます。インストーラは TTS を選んだあと、そのモデルだけ受け取り、それからプログラムをコピーします。選ばなければ Kokoro-82M です。
2. 初めて開くと言語を選びます。インストーラが声をすでに残していれば TTS は聞きません。
3. **接続** で付ける文を**もう一度**コピーしてボット窓に入れます。Grok Bot は登録した Windows で承認してチェックインすると付きます。来なければボットの `GROK_CREW_OK` をここに貼ります。コピーしただけでは接続されません。
4. **自動** でやりたいことを書いて **作成** を押します。この窓は待ちます。**クルーボード**で誰が何をして、次の席に残した一行を見ます。
5. プレビューが出たら **このPCに保存** します。投稿はそのあと、したいときだけです。

付かなければ **接続** が直し方を書きます。先に自動を開かないでください。

## v1.0.0 で変わったこと

以前の Grok-Crew（0.2.1）はブラウザの作業台に近いものでした。いまの 1.0.0 は **このPCの窓** です。

- 接続・自動・設定・編集・書き出しが同じ書き方です。やること一つ、ほかはチップ。
- **Grok Bot** と **Agent** を企画・収集・編集で付けます。内蔵スキルが一緒に行きます。
- 付ける文をコピーするだけです。返事をこの窓に貼り直しません。ボットに `127.0.0.1` を見せません。
- 字幕・吹き替え・TTS は入れたときだけ動きます。最初は全部オフです。初回に声の選択で止まりません。
- できたファイルはこのPCに残ります。GitHub の受信箱はなくても動きます。
- ペアコードは暗号用の乱数です。GitHub トークンの失敗でトークンを書き戻しません。

1.0.0 の一覧は [CHANGELOG.md](CHANGELOG.md) と [1.0.0 リリースノート](docs/RELEASE_NOTES.v1.0.md) です。

## 画面にあるもの

各タブは **今やること一つ** です。ほかはチップを押すまで閉じています。

| タブ | すること |
|---|---|
| **接続** | ボットを付ける・外す。このPCで使う、ほかの窓、ボットなしで映像を開くは折りたたみです。 |
| **自動** | やりたいことを一欄。チップ：画面 / 出す先 / 音。作成のあと：待ち → プレビュー → 保存。 |
| **設定** | 形・長さ・音・テンポ。ここのボタンは **設定だけ保存** です。 |
| **編集** | タイムラインとプレビューが先。届いたファイルとプロキシは折りたたみです。 |
| **書き出し** | このPCへの保存が先。投稿・交換・記録はチップです。 |
| **上級仕様** | 題と目標。スタイル・元・集め・ファイルはチップ。保存したあとだけ送受信が開きます。 |

左の **版の記録**、右の GitHub・制作機は折りたたみです。開いたときだけ見えます。

## これは何かではないか

- クラウド編集や、ブラウザで切るサイト
- 「こちらが動画を作る」サブスク
- Instagram / TikTok への自動投稿
- ログイン中のSNSを掻くこと
- ボットに `127.0.0.1` を見せること

## 窓の下で使っている技術

客は見なくて大丈夫です。インストーラを開けば使えます。

| 役割 | 使うもの |
|---|---|
| 窓 | Electron。このPCのプログラムです。 |
| 画面 | React と TypeScript。接続・自動・設定・編集・書き出しです。 |
| 仕上げ | このPCの Python 制作機（Local Studio）。この窓とだけ話します。 |
| 保存 | このPCの SQLite。アカウントサーバはありません。 |
| 切る・つなぐ | 保存時にこのPCで ffmpeg と MoviePy が動きます。 |
| 字幕 | 字幕を入れたときだけ whisper.cpp。 |
| 声 | TTS を入れたときだけ、選んだエンジン **一つ**。 |
| ボットスキル | `public/bot-skills/` の Markdown。接続時に付きます。 |

音声モデルはインストーラに入れていません。その機能を入れたあとだけダウンロードします。

## このリポジトリを開く

公開ソース：[NoLucas/Grok-Crew](https://github.com/NoLucas/Grok-Crew)

```bash
git clone https://github.com/NoLucas/Grok-Crew.git
cd Grok-Crew
npm install
npm run local
```

客の窓は `npm run desktop` です。ブラウザだけで机を見るなら `npm run dev` を実行し、表示されたアドレスを開きます。

詳しい入れ方は [docs/BUILD.ko.md](docs/BUILD.ko.md) です。
