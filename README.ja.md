# Grok Crew

<p align="center"><a href="README.md">English</a> &nbsp;·&nbsp; <a href="README.ko.md">한국어</a> &nbsp;·&nbsp; <a href="README.zh.md">简体中文</a> &nbsp;·&nbsp; <strong>日本語</strong></p>

**[Windows で開く](https://github.com/NoLucas/Grok-crew-test/releases/latest)** — [`GrokCrew-Windows.exe`](https://github.com/NoLucas/Grok-crew-test/releases/latest) を受け取ってダブルクリックします。

五回です。受け取る → 開く → つなぐ → 自動に書く → 貼る。

1. **受け取る** — ファイルは一つ、`GrokCrew-Windows.exe`。
2. **開く** — ダブルクリック。青い保護画面なら 詳細情報 → 実行。
3. **つなぐ** — 上の **接続** メニューでします。一番上が別 PC（Grok Bot・自分のエージェント）です。接続文を貼り、ボットが返した `GROK_CREW_OK` の一行を戻します。緑のランプと **接続済み** なら付いたことです。
4. **書く** — **自動** タブに今日出す言葉。
5. **貼る** — 開始が仕事をコピーします。その窓に貼ります。カットが届くとこのタブにプレビューが残り、保存を聞きます。

自分の映像を切るなら自動の **自分のファイルで始める** に置きます。ログインはありません。

素材を預けるサイトではありません。ボットはこの PC を開かず、パッケージだけ送ります。

```
exe を受け取る  →  開く  →  つなぐ  →  自動に書く  →  仕事を貼る  →  プレビューしてこの PC に保存
```

## だれ向けか

- リールの仕様だけ決めたい人
- 接続したボットに素材と初回カットを任せたいが、ドアは混ぜたくない人
- 完成ファイルはそれでもこの PC に置きたい人

今は無料です。始めるのにアカウントは不要です。カードも定期課金も聞きません。

## 画面に出るもの

最初の画面は **接続** メニューです。別 PC が一番上です。この PC・Local Studio・GitHub・Runner もそこでつなぎます。緑のランプが **接続済み** です。ボットが付くか **自分のファイルで始める** で映像を開くと **自動** に着地し、設定・編集・書き出しが付きます。**自動**は今日出す言葉、どんな映像か、資料（自分の映像・写真 / 収集ボットが持ってくるもの）と開始一つです。このアプリは掻きません。任せる／自分のファイルは自動の中の二つの道です。接続 UI は自動に再描画しません。サンプルは **サンプルで画面を見る** だけで開きます。コピーのあとは接続・仕事を送った・作業中・カット到着・この PC に、経過時間、まだない / 到着 / 失敗を人の言葉で出します。この窓はボットが招待文を読んだとは言いません。保存カードはこの PC のフォルダを書き、自動では上げていないと書きます。python・ポート・フォルダ経路は開くまで隠しです。**もっと詳しく**と**高度なツール**は初回カットが届いてから大きくなります。編集ドアに届いたカットはボタンなしで開き、プレビューは自動タブに残ります。ボットが置いたフォルダは1行に畳まれ、開くと左が一覧・右がプレビューです。右クリックでプレビュー・拡大・原本表示・削除を選べます。画質は仕様ロック、画面比・字幕と残りの編集操作はデスクで変えられます。設定でショート・リール・TikTok などのスタイルを選ぶか、今の値を名前で保存できます。明るい昼・暗い夜・やわらかい昼・やわらかい夜と文字は左上の歯車で変えます。このデスクはサイトを掻きません。

そのあとは 5 つのタブです。

| タブ | 用途 |
| --- | --- |
| **接続** | 別 PC、この PC、Local Studio、GitHub、Runner |
| **自動** | 今日の言葉 → 送る → 待つ → プレビュー → 保存 |
| **編集** | プレビューを見ながらタイムラインで切る |
| **設定** | ルック、字幕、速度 |
| **書き出し** | この PC に MP4 を残す。投稿するなら確認のあと |

プレビューは編集中に画面が遅れないための速い下書きです。保存するファイルは原版から作ります。

## 映像はこのパソコンに残ります

原版、編集、完成ファイルはこの PC にあります。Grok Crew のクラウドプロジェクトも、始めるためのログインもありません。

投稿は任意です。初期値は **公開前に確認** です。すでに送った可能性があるときは、二通目の前にもう一度聞きます。Instagram・TikTok・YouTube のアカウントは Grok Crew が作りません。

## 任意: この PC の AI に頼む

AI が**同じパソコン**ですでに動いているなら、普段の言葉で頼めます。強いセリフだけ残して、字幕を入れて、縦に切って、ファイルはここに置いて、アップロードはしないで。

別のパソコンの AI はこの机を開けません。**接続** メニューは名前だけつなぎ、終わったカットはこの窓に置きます。よそにあるボットに「ちょっと見せて」と映像を送りません。

## 開き方

**Windows で開く** — [最新リリース](https://github.com/NoLucas/Grok-crew-test/releases/latest)の `GrokCrew-Windows.exe` を受け取ってダブルクリックします。このアカウントだけに入ります。管理者パスワードは聞きません。

Windows が PC を保護したと言ったら **詳細情報 → 実行**。

すでに誰かが入れてくれているなら、Grok Crew の窓を開くか、ブラウザで [http://localhost:3000](http://localhost:3000/) です。

ソースから動かすなら [Node.js 22+](https://nodejs.org/) と [Python 3.10+](https://www.python.org/downloads/) が必要です。

```sh
git clone https://github.com/NoLucas/Grok-Crew.git grok-crew
cd grok-crew
npm run local
```

ソースから窓で使うなら、一度 `npm install` してから `npm run desktop` です。初回は数分かかることがあります。止めるときは `Ctrl+C`。

このパソコンで自分の動画を作って公開できます。ソースは [BUSL-1.1](LICENSE) で公開されており、オープンソース製品ではありません。質問: [CONTRIBUTING.md](CONTRIBUTING.md)。
