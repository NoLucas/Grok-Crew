# Grok Crew

客のPCで動くプログラムです。すでに使っているボットを付ければ、できたファイルは **このPCのフォルダ** に残ります。

ログインなしで開きます。サイトのサブスクではありません。

[Windows を入手](https://github.com/NoLucas/Grok-crew-test/releases) · [한국어](README.ko.md) · [English](README.md) · [中文](README.zh.md)

---

## 使い方

1. **Windows を入手** から入れて開きます。アカウントはありません。
2. **接続** で使っているボットを付けます。付ける文をコピーしてボット窓に入れます。
3. **自動** でやりたいことを書いて **作成** を押します。
4. 人がボット窓に貼ります。この窓は待ちます。
5. プレビューが出たら **このPCに保存** します。投稿はそのあと、したいときだけです。

付かなければ **接続** が直し方を書きます。先に自動を開かないでください。

---

## 画面にあるもの

各タブは **今やること一つ** です。ほかはチップを押すまで閉じています。

| タブ | すること |
|---|---|
| **接続** | ボットを付ける・外す。このPCで使う、ほかの窓、ボットなしで映像を開くは折りたたみです。 |
| **自動** | やりたいことを一欄。チップ：画面 / 出す先 / 音。作成のあと：待ち → プレビュー → 保存。 |
| **設定** | 形・長さ・音・テンポ。ここのボタンは **設定だけ保存** です。 |
| **編集** | タイムラインとプレビューが先。届いたファイルとプロキシは折りたたみです。 |
| **書き出し** | このPCへの保存が先。投稿・交換・記録はチップです。 |
| **上級仕様** | 題と目標。スタイル・元・集め・ファイルはチップ。保存したあとだけ送受信が開きます。 |

字幕・吹き替え・TTS は客が入れたものだけ動きます。最初は全部オフです。

左の **版の記録**、右の GitHub・制作機は折りたたみです。開いたときだけ見えます。

## 今回変わったこと

- 五つのタブが同じ書き方です。やること一つ + チップ。機能はそのまま、使わないパネルは閉じています。
- **接続** は付ける文をコピーするだけです。返事をこの窓に貼り直しません。
- できたファイルは **このPC** に残ります。投稿は保存のあと、したいときだけです。
- Git でファイルを渡すのは、客が自分で入れた **個人リポジトリ** のときだけです。会社共用の受信箱はありません。なくてもこのプログラムは動きます。

---

## これは何かではないか

- クラウド編集や、ブラウザで切るサイト
- 「こちらが動画を作る」サブスク
- Instagram / TikTok への自動投稿
- ログイン中のSNSを掻くこと
- ボットに `127.0.0.1` を見せること

## 窓の下で使っている技術

客は見なくて大丈夫です。インストーラを開けば使えます。

自分で直す・ビルドするときだけ：

| 役割 | 使うもの |
|---|---|
| 窓 | Electron。このPCのプログラムです。 |
| 画面 | React と TypeScript。接続・自動・設定・編集・書き出しです。 |
| 仕上げ | このPCの Python 制作機（Local Studio）。この窓とだけ話します。完成ファイルをネットに上げません。 |
| 保存 | このPCの SQLite。アカウントサーバはありません。 |
| 切る・つなぐ | 保存時にこのPCで ffmpeg と MoviePy が動きます。 |
| 字幕 | 字幕を入れたときだけ whisper.cpp。 |
| 声 | TTS を入れたときだけ、選んだエンジン **一つ**。 |
| 別PCのボット | 基本はこの窓とこのPCのフォルダです。git は客が自分の非公開リモートを入れたときだけです。 |

音声モデルはインストーラに入れていません。その機能を入れたあとだけダウンロードします。

## このリポジトリを開く

公開ソース：[NoLucas/Grok-crew-test](https://github.com/NoLucas/Grok-crew-test)

```bash
git clone https://github.com/NoLucas/Grok-crew-test.git
cd Grok-crew-test
npm install
npm run local
```

客の窓は `npm run desktop` です。ブラウザだけで机を見るなら `npm run dev` を実行し、表示されたアドレスを開きます。

詳しい入れ方は [docs/BUILD.ko.md](docs/BUILD.ko.md) です。
