## 给谁用

- **懒得自己剪 Shorts 的人。** 不用从零搭时间线。写下想做的事，贴进机器人窗口，在这里保存。
- **现在免费。** 没有登录。不是订阅。也没有按条积分。
- **文件留在这台电脑。** 不是云端剪辑器。

这个窗口不是“我们来生成视频”的订阅。它是接上你已有机器人的程序。

## 给机器人和 Agent 的内置技能

连接时，座位已经带好技能。不必自己写策划、抓取、剪辑提示词。

| 座位 | 基础技能 | 一并带上的额外技能 |
|---|---|---|
| **Grok Bot / Agent 策划** | `planner` — 把今天的话写成剪辑计划 | `edit-plan` — 给抓取和剪辑读的短计划 |
| **Grok Bot / Agent 抓取** | `scraper` — 只挑公开页面 | `public-pick` — 不写登录墙里的社交应用 |
| **Grok Bot / Agent 剪辑** | `editor` — 按计划剪 | `cut-to-plan` — 守场景顺序和目标市场的节奏 |

原文在 [`public/bot-skills/`](public/bot-skills/)。复制接上用的文字时，该座位的技能一起走。这个程序不抓网站。

## 怎么用

1. 从 **下载 Windows** 安装并打开。没有账号。
2. 在 **连接** 把接上用的文字复制到机器人窗口。Grok Bot 应在已登记的 Windows 上批准后签到。没到的话，把机器人回的 `GROK_CREW_OK` 贴回这里。只复制不算已连接。
3. 在 **自动** 写下想做的事，按 **制作**。
4. 人把内容贴进机器人窗口。这个窗口等待。
5. 预览出来后 **存到这台电脑**。发布是下一步，而且只有他们想发时才做。

接不上时，**连接** 会写怎么修。不要先开自动。

## v1.0.0 改了什么

以前的 Grok-Crew（0.2.1）更像浏览器工作台。现在的 1.0.0 是 **这台电脑上的窗口**。

- 连接、自动、设置、编辑、导出同一套写法：一件事，其余是芯片。
- **Grok Bot** 和 **Agent** 按策划、抓取、剪辑接上。内置技能一起走。
- 只复制接上用的文字。不用把回复再贴回这个窗口。不把 `127.0.0.1` 给机器人看。
- 字幕、配音、TTS 默认全关，打开才跑。第一次打开不挡在选声页面。
- 成品留在这台电脑。GitHub 收件箱可有可无。
- 配对码用密码学随机数。GitHub 令牌出错时不再把令牌写回去。

1.0.0 列表见 [CHANGELOG.md](CHANGELOG.md) 和 [1.0.0 发布说明](docs/RELEASE_NOTES.v1.0.md)。

## 屏幕上有什么

每一栏只做 **一件事**。其余工具在芯片后面，问了才开。

| 栏 | 做什么 |
|---|---|
| **连接** | 接上或拆掉机器人。本机使用、其他窗口、不接机器人直接打开影片都收着。 |
| **自动** | 一栏提示。芯片：画面 / 要发到哪 / 声音。制作之后：等待 → 预览 → 保存。 |
| **设置** | 形态、长度、声音、节奏。这里的按钮是 **只保存设置**。 |
| **编辑** | 时间线和预览在前。收件文件和代理预览收着。 |
| **导出** | 先存到这台电脑。发布、交换、记录是芯片。 |
| **高级规格** | 标题和目标。风格、来源、收集、文件是芯片。只有保存之后才打开发件/收件。 |

左边 **版本记录**、右边 GitHub / 制作器默认收着，打开才看见。

## 窗口下面用了什么

客人可以不看。打开安装包即可。

| 工作 | 用什么 |
|---|---|
| 窗口 | Electron。这台电脑上的程序。 |
| 界面 | React、TypeScript。连接、自动、设置、编辑、导出。 |
| 剪辑 | 这台电脑上的 Python 制作器（Local Studio）。只和这个窗口说话。 |
| 存储 | 这台电脑上的 SQLite。没有账号服务器。 |
| 编码 | 保存时在这台电脑跑 ffmpeg、MoviePy。 |
| 字幕 | 只有打开字幕时才用 whisper.cpp。 |
| 声音 | 只有打开 TTS 时才用选中的 **一个** 引擎。 |
| 机器人技能 | `public/bot-skills/` 里的 Markdown，连接时贴上。 |

语音模型不打进安装包。客人打开该功能后才下载。

## 打开这个仓库

公开源码：[NoLucas/Grok-Crew](https://github.com/NoLucas/Grok-Crew)

```bash
git clone https://github.com/NoLucas/Grok-Crew.git
cd Grok-Crew
npm install
npm run local
```

客人窗口是 `npm run desktop`。只想在浏览器里看桌面，运行 `npm run dev` 再打开它打印的地址。

完整安装说明：[docs/BUILD.ko.md](docs/BUILD.ko.md)。
